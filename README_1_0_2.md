# NiniAnalyzer_Public 1.0.2

1.0.1을 고친 판입니다. 똬리의 제단 신화 판정 3개를 바로잡았습니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.2_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.2_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.
- 이미 분석한 트라이는 「재분석」하면 고친 판정으로 다시 나옵니다.

## 고친 것 (똬리의 제단 신화)
- **P2 진입 잔여 구슬이 실패로 나오던 문제**
  - P2 진입 때 남은 구슬 수를 전투가 끝날 때 값으로 계산해서, 킬 트라이도 「활성 구슬 32개 · 실패」처럼 나왔습니다. (P3 웨이브 구슬이 계속 더해진 값)
  - 이제 P2에 들어간 그 시점의 구슬 수로 계산합니다. 진입 직전 일괄 파열로 다 지웠으면 성공으로 나옵니다.
- **P1→P2 진입이 몇 초만 빨라도 실패로 나오던 문제**
  - 목표(2:45~2:50)보다 6초 이내로 빠르거나 5초 이내로 늦으면 「주의」로 나오고, 몇 초 벗어났는지 같이 보여 줍니다.
  - 2단두대 무렵(2:10 안팎)에 넘기는 것처럼 크게 벗어나면 그대로 실패입니다.
- **보호막을 다 깼는데 쿨기 정렬이 실패로 나오던 문제**
  - 보호막이 제때 깨졌으면 쿨기 미사용/지연은 「참고」로만 보여 줍니다.
