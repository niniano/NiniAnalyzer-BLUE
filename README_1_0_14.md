# NiniAnalyzer_Public 1.0.14

「한눈에 보기」 무너진 순서 칩을 시각 순서로 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.14_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.14_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **무너진 순서 시각 순**: 「4:37 첫 실수 → (시각 없음) → 4:30」처럼 칩이 거꾸로 나오던 것을 시각 순서로 고쳤습니다.
  · 시각이 비어 있던 칩은 바로 다음 단계의 시각을 씁니다.
  · 「산성 배출 1회」 같은 횟수 요약 칩은 제자리에 둡니다.
  · 첫 실수보다 앞선 단계가 있으면 그 단계가 「뿌리」로 맨 앞에 오고, 첫 실수 표시는 그대로 남습니다.
