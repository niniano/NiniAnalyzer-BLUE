# NiniAnalyzer_Public 1.0.10

결론 칸 글이 잘리던 것을 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.10_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.10_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **참고 줄 잘림 고침**: 「이번 트라이 · 한눈에 보기」의 다음 풀 · 참고 줄에서 마지막 줄이 조금 잘려 스크롤해야 보이던 것을 고쳤습니다.
  이름(직업색)이나 굵은 기믹 이름처럼 큰 글자가 섞인 줄은 한 줄 높이가 더 커서, 줄 수만 세면 모자랐습니다.
  이제 글 전체 높이에 맞춰 칸 크기를 정합니다. Windows 화면 배율(125% · 150%)에서 특히 잘 보입니다.
