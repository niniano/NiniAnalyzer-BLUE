# NiniAnalyzer_Public 1.0.13

감시를 켜기 전에 지나간 풀을 자동으로 채우는 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.13_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.13_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **놓친 트라이 채우기**: 실시간 감시는 켠 뒤의 풀만 잡습니다. 그래서 공대 도중에 프로그램을 껐다 켜거나 감시를 늦게 켜면 그 사이 풀이 비었습니다.
  이제 「감시 시작」을 누르면 지금 쓰는 전투 로그에서 아직 저장 안 된 풀을 뒤에서 자동으로 채웁니다.
  · 놓친 풀이 없으면 아무 일도 하지 않습니다 (로그를 다시 읽지 않음).
  · 이미 저장된 풀과 지금 진행 중인 풀은 건너뜁니다.
  · 풀 하나를 채울 때마다 목록에 바로 나타나고, 아래 상태줄에 진행 상황과 결과(「놓친 트라이 없음」 포함)가 보입니다.
  · 공대 도중에 와우를 껐다 켜서 전투 로그 파일이 여러 개여도 그날 파일을 모두 확인합니다.
  · 기존 기록 확인(재분석)이 진행 중이면 끝난 뒤에 채웁니다.
- **Try 번호 시간순**: 나중에 채운(또는 「로그 가져오기」로 넣은) 풀 때문에 번호가 어긋나지 않게, 같은 날 · 같은 보스의 Try 번호를 시작 시각 순서로 다시 매깁니다.
