# NiniAnalyzer_Public 1.0.23

울라텍 송곳니 줄을 늦게 끊은 사람과, 탱이 죽어서 무너진 트라이를 잡아내는 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.23_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.23_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 송곳니 줄 늦게 끊음**: 송곳니 줄을 끊으면 공대 전체에 「역병의 핏줄」이 걸려 2초마다 3번 맞습니다 (줄 하나당 1중첩).
  · 핏줄이 걸려 있는 동안 2틱이 지난 뒤에 끊으면 중첩이 그대로 연장돼 공대 전체가 6중첩 틱을 한 번 더 맞습니다.
  · 그런 사람을 「줄」에 「늦게 끊음 ❌ 이름 (+n초)」로, 핏줄 틱이 몇 번 들어왔는지와 함께 보여 줍니다.
  · 늦게 끊고 바로 공대가 무너졌으면 첫 실수 · 전멸 원인으로 잡습니다. 다음 풀 조언은 「다 같이 끊고, 늦었으면 2틱 보고 끊기」입니다.
- **늦으면 2틱 보고**: 늦었어도 핏줄이 끝난 뒤에 끊었으면 새 핏줄 1중첩부터라 「늦었지만 핏줄 끝나고 끊음 ✅」로 봅니다.
- **탱 사망 → 붕괴**: 다른 뿌리(살무사 · 큰 알 · 송곳니 · 똥물)가 없고 붕괴 3~20초 전에 탱이 죽었으면 그게 첫 실수 · 전멸 원인입니다.
  · 탱이 죽기 직전 무엇에 맞았는지(괴저 증기 빼고) 상위 3개를 적습니다.
  · 다음 풀 조언은 맞은 것에 따라 다릅니다: 약화된 파멸비늘 → 「2마리는 탱 둘이 하나씩」 · 흉물 → 독성 배양 탱 교대 · 유체 → 유체 모아 잡기 · 보스 → 탱 교대 공백 없이.
