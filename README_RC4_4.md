# NiniAnalyzer Public 1.0.0-rc4.4 · 빌드 키트

RC4.3(배포판)에 **폰트 중복 등록 수정**만 추가한 버전입니다. 엔진·저장 파일·다른 기능은 RC4.3과 같습니다.

## 고친 것
- 증상: 펴진고딕/페이퍼로지를 윈도우에 **직접 설치한 PC**에서 한글 제목이 잘리거나(「체크」→「체」) 겹치고 자간이 벌어짐
- 원인: 설치된 폰트 + 프로그램이 따로 불러온 같은 폰트(FR_PRIVATE)가 동시에 등록돼 윈도우가 글자 폭을 잴 때와 그릴 때 서로 다른 폰트를 씀
- 수정: 실행 시 윈도우 폰트 목록(사용자 설치 + 전체 설치)을 먼저 확인하고, **같은 폰트·같은 굵기가 이미 설치돼 있으면 따로 불러오지 않음**
  - 설치 안 된 폰트만 기존처럼 프로그램 안에서만 불러옴 (시스템에는 아무것도 남기지 않음)
  - 다른 굵기(예: 페이퍼로지 4 Regular)만 설치된 경우는 다른 폰트로 보고 기존처럼 불러옴
  - 폰트 목록을 못 읽으면 기존 방식 그대로

## 빌드
`Build_Public_EXE.cmd` → `dist\NiniAnalyzer_Public_1.0.0-rc4.4_Setup_Windows_x64.exe`
같은 AppId라 기존 설치 위에 그대로 업데이트됩니다(기록 유지).

## 확인할 것 (짧게)
1. 설치 후 왼쪽 위 버전 `v1.0.0-rc4.4`
2. **폰트 설치한 상태**에서 제목(「선풀·전멸 체크」 등)이 잘리거나 겹치지 않는지
3. 폰트 지운 상태에서도 지금처럼 정상인지
