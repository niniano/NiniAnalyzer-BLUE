# NiniAnalyzer_Public 1.0.1

1.0.0을 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.1_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.1_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.
- 이미 분석한 트라이는 「재분석」하면 고친 판정으로 다시 나옵니다.

## 고친 것
- **블러드를 안 썼는데 썼다고 나오던 문제**
  - 증강 기원사의 「위상의 격노」가 블러드가 아닐 때도 본인에게만 몇 초씩 걸리는데, 이걸 블러드로 보고 풀 직후(0:04 등)에 BL 구간이 그려졌습니다.
  - 이제 블러드 계열 버프는 시전 기록이 있거나, 1.5초 안에 3명 이상에게 걸리거나, 블러드 피로 디버프(탈진 · 만족 등)가 같이 걸렸을 때만 블러드로 봅니다.
  - 똬리 보호막 계획의 「블러드 사용」 판정도 같은 기준입니다.
