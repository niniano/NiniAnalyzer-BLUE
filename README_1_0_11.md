# NiniAnalyzer_Public 1.0.11

「한눈에 보기」를 보기 좋게 다듬은 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.11_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.11_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.
- 1.0.10 을 받지 않았다면 1.0.10 의 바뀐 것(한눈에 보기 · 글 잘림 고침)도 이 판에 다 들어 있습니다.

## 바뀐 것
- **무너진 순서 한 줄**: 칩을 한 줄에 같은 폭 · 같은 높이로 놓고, 긴 글은 칩 안에서 줄바꿈합니다. 끝 「전멸」 칩만 제 크기입니다.
- **굵은 화살표**: 칩 사이 화살표를 굵게, 칩 높이 가운데에 둡니다.
- **둥근 테두리**: 칩 · 숫자 카드 · 다음 풀 칸을 옆 「기믹 수행 체크」 카드처럼 둥글게.
- **같은 칩 두 번 고침**: 첫 실수와 전멸 원인 첫 단계가 같은 글이면 한 번만, 글이 「전멸」뿐인 단계는 끝 칩과 합칩니다.
  「1심장 종료 보스 67.3%」처럼 심장 단계 이름은 지우지 않습니다.
- **버튼 하나**: 「판정 상세 펼치기」와 「자세히 펼치기」를 칸 제목 오른쪽 「자세히 펼치기 ▾」 하나로 합쳤습니다.
  (예전 「판정 상세」 칸은 결론 5줄과 같은 내용이라 결론 칸이 있는 트라이에서는 빠집니다.)
- **「B31 원본 · 개인 사망 · 쿨기 비교 상세」 버튼 없앰**: 같은 글은 위 「개인 사망 열기」 · 「전멸 복기 열기」 버튼으로 파일을 열면 그대로 있습니다.
- **오피격 → 같이 맞음**: 탱 브레스를 탱커가 아닌 사람이 맞은 것을 「같이 맞음」으로 씁니다 (화면 글자만 · 판정은 그대로).
