# NiniAnalyzer_Public 1.0.19

공대마다 다른 택틱을 「공대 계획」으로 적어 두고, 울라텍 알방 남쪽 구역을 판정하는 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.19_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.19_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **공대 계획 (왼쪽 「공대 계획」)**: 공대마다 택틱이 달라서, 울라텍 큰 알 집기·넣기 시각과 남쪽 구역 택틱을 우리 공대 기준으로 적어 둡니다.
  · 비워 두면 큰 알 시각은 판정하지 않고, 보스 기믹으로 정해진 것(안 집은 큰 알 → 공포의 포효 · 유체 광폭 등)만 봅니다.
  · 전에는 모든 공대를 「4:18 집기 · 4:30 넣기」 한 기준으로 봤습니다.
  · 트라이 결론에 「계획」 줄이 생겨 어떤 기준으로 판정했는지 보입니다.
- **울라텍 남쪽 구역**: 알방 남쪽 구역(큰 알 + 보호막 알 2개)을 「남쪽」 줄로 보여 줍니다.
  · 보호막 알을 깼는지 · 들었는지 → 큰 알을 집을 때 산란무리가 생겼는지 → 남쪽 유체가 광폭(산성 배출) 전에 잡혔는지
  · 1번 = 보호막 알 2개를 먼저 깨고 들어서 가마솥 → 그다음 큰 알 · 2번 = 보호막 알은 두고 큰 알부터 (보호막 알 → 산란무리 → 남쪽에서 유체)
  · 택틱은 「공대 계획」에서 직접 고릅니다. 고르지 않아도 트라이마다 「실제 1번처럼 / 2번처럼 / 섞임」은 로그로 보여 줍니다.
  · 계획이 1번(보호막 알 먼저)이면 보호막 알이 남은 채 큰 알을 집었을 때 ⚠, 2번(큰 알 먼저)이면 남쪽 유체가 광폭했을 때 ⚠
- 이미 본 트라이는 「다시 분석」하면 새 기준으로 나옵니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
