# NiniAnalyzer_Public 1.0.17

울라텍 큰 알 판정을 공대 공략 시각에 맞춘 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.17_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.17_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 큰 알 4:18 · 4:30**: 큰 알 줄이 「들기 4:18 → 실제 · 마지막 알림 4:19 · 부화 4:24 · 넣음 … (공략 4:30쯤)」으로 나옵니다.
  · 가마솥에 넣은 시각은 4:31을 넘겨야 늦음으로 봅니다 (전에는 4:28).
  · 다음 풀 조언과 「큰 알 가마솥 늦음」 원인 문구도 4:18에 집어 4:30쯤 넣기로 바뀝니다.
  · 이미 본 트라이는 「다시 분석」하면 새 기준으로 나옵니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
