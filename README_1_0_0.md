# NiniAnalyzer_Public 1.0.0

첫 정식판입니다. 10월 22일 rc5부터 길드에서 써 온 시험판(rc5.x)을 정리했고, 내용은 rc5.6과 같습니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.0_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.0_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 설치 · 업데이트
- **처음**: 설치 파일 실행 → 다음 → 설치. 관리자 권한 필요 없음.
- **「Windows의 PC 보호」 파란 창**: 서명 안 된 프로그램이라 뜰 수 있습니다 → 「추가 정보 → 실행」.
- **rc5.x 쓰던 분**: 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 쓰는 법 (요약)
1. 게임에서 고급 전투 기록 켜기 · `/combatlog`
2. 왼쪽 「설정」에서 `World of Warcraft\_retail_\Logs` 폴더 선택
3. 「최신 로그 분석」 → 왼쪽 「레이드 세션 > 보스 > 트라이」에서 복기
