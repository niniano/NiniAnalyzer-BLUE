# NiniAnalyzer_Public 1.0.18

울라텍 살무사 원인에 「알 깨짐」을 더한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.18_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.18_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 알 깨짐 → 살무사**: 알이 깨지면 공대 전체에 「부패한 막」이 한 번에 걸리는 것을 읽어 원인을 찾습니다.
  · 그 순간 알을 놓친 사람이 있으면 「알 든 ○○ 알 깨짐 m:ss (공대 전체 부패한 막)」 [확정]
  · 아무도 안 든 알이 깨졌으면 「아무도 안 든 알 깨짐」 + 다음 풀 조언 「바닥에 알 남기지 않기」
  · 전에는 「원인 미확인 (알 운반 밖)」 또는 「알 놓침」 [추정]으로 나오던 트라이입니다.
  · 이미 본 트라이는 「다시 분석」하면 새 기준으로 나옵니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
