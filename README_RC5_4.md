## 바뀐 것 (공대원이 보는 화면)
- **결론 5줄과 단계 칩**: 전멸 트라이 맨 위에 어디까지 · 첫 실수 · 전멸 원인 · 딜·힐 · 다음 풀이 나옵니다.
  - 단계 칩 색: 넘긴 단계는 초록, 전멸한 단계는 빨강, 못 간 단계는 회색입니다.
- **색**: 기믹 이름은 종류마다 늘 같은 색이고, 캐릭터 이름은 직업색입니다.
- **기믹 시간축**: 기본 보기가 「스킬별」 줄(Viserio 방식)입니다. 「한 줄」 · 「상세(기존)」로 바꿀 수 있습니다. 아이콘 테두리는 1px입니다.
- **공략 판정 보스**: 똬리 · 울라텍에 더해 스조라크 · 쌍둥이 송곳니 · 매장된 파수꾼 · 악성의 바쉬니크 · 영혼살무사 네크잘리 · 길 잃은 탐험가가 추가됐습니다.
  - 네크잘리: 「각성의 그릇 (시체 못 태움)」을 판정합니다. 각성의 그릇은 죽은 잠 못 드는 아마니가 남기는 시체로, 굶주린 장작더미나 기어가는 불꽃(화장)으로 태워야 합니다.
  - 네크잘리: 고뇌의 메아리 착지 · 잠복한 이교도 장판 · 화장 폭발 사망도 따로 구분합니다.

- **세로 모니터**(예: 1440×2560): 창이 1440×1640으로 열리고 화면 밖으로 나가지 않습니다. 환경변수 `WCLA_TALL=0`이면 꺼집니다.
