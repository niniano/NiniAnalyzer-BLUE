# NiniAnalyzer_Public 1.0.3

1.0.2에 처음 쓰는 사람을 위한 안내와 새 소식 카드를 더한 판입니다. 분석 결과는 1.0.2와 같습니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.3_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.3_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **첫 실행 안내 카드**
  - 처음 켜면 메시지 상자 대신 3단계 카드가 뜹니다: ① 게임에서 전투 기록 켜기 ② WoW 로그 폴더 ③ 최신 로그 분석
  - 로그 폴더를 찾았는지 바로 보이고, 그 자리에서 폴더를 고르거나 분석을 시작할 수 있습니다.
- **새 소식 카드**
  - 새 버전으로 처음 켜면 바뀐 내용을 카드로 한 번 보여 줍니다. (새로 설치한 경우는 첫 실행 안내만)
  - 왼쪽 위 버전 글자를 누르면 언제든 다시 볼 수 있습니다.
