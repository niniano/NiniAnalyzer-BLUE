# NiniAnalyzer_Public 1.0.28

레이드 세션 화면의 빈 「오늘의 교정」 칸을 채운 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.28_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.28_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **오늘의 교정**: 레이드 세션 화면 오른쪽 아래 「오늘의 교정」 칸이 비어 있었습니다. 이제 그날 똬리의 제단 · 울라텍 보완사항을 보스별로 보여 줍니다 (트라이 보드 「보완사항」과 같은 내용). 처음엔 계산하는 동안 「계산 중 n/m트 · 멈춘 거 아님」이 보이고, 똬리 · 울라텍이 없는 날은 그렇다고 적습니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
