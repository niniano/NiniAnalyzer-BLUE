# NiniAnalyzer_Public 1.0.16

NiniTools 계정 달력의 공대 초대를 내 구글 캘린더로 옮기는 기능을 넣은 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.16_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.16_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **WoW 달력 → 구글 캘린더** (선택 · 기본 꺼짐): 왼쪽 「WoW 달력 → 구글」 → 「구글 연결」 → 브라우저에서 내 구글 계정 고르고 「허용」.
  · NiniTools 「계정 달력」이 모은 캐릭터별 초대가 구글 캘린더 「니니 레이드 (WoW)」에 들어갑니다 (응답에 따라 색 · 30분 전 알림).
  · 분석기가 켜져 있으면 게임을 끄거나 /reload 할 때마다 자동으로 맞춥니다. 시간이 바뀌거나 취소된 초대도 따라 바뀝니다.
  · 권한은 「이 앱이 만든 캘린더만」 하나라 내 다른 일정은 읽지도 고치지도 못합니다.
  · 구글 로그인이 끊기면 창에 「구글 다시 연결」이 뜹니다.
  · 구글 연결 없이 쓰려면 「.ics 파일로 내보내기」 → 구글 캘린더 설정 → 가져오기.
  · NiniTools 계정 달력이 켜져 있어야 합니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 달력 기능을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다. 구글 로그인 정보는 이 PC에만 저장됩니다.
