# NiniAnalyzer_Public 1.0.9

울라텍 신화 「알 운반」 카드를 더한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.9_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.9_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 알 운반 카드**: 오른쪽 「기믹 수행 체크」 아래에 `알 운반 · 누가 들었나` 카드가 생겼습니다.
  - 1차(0:15쯤) · 2차(1:25쯤) · 알방(3:40쯤)마다 작은 알을 든 사람, 마지막 줄에 큰 알 4개(든 시각 → 넣은 시각)를 보여 줍니다.
  - 문제는 빨강(`파도 2:01 → 살무사 2:01` · `충돌` · `먼저 놓음` · `들고 사망`), 늦은 큰 알은 주황, 전멸이 시작된 뒤에 생긴 것은 회색(`전멸 2:14`)입니다.
  - 문제 있는 사람이 그 줄 맨 앞에 옵니다.
- **참고 줄 짧게**: 누가 들었는지는 카드로 옮기고, 결론 아래 참고 줄에는 `알 든 사람 부식의 파도 2번 · 알 충돌 1번 → 살무사 8마리`처럼
  횟수와 결과만 남겼습니다. 결론 칸이 짧아져 스크롤 없이 보입니다.
- 결론 칸은 트라이를 열 때 다시 계산하므로 예전 기록도 다시 열면 카드가 보입니다.
