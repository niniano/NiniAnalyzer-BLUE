# NiniAnalyzer_Public 1.0.24

울라텍과 똬리의 제단 전멸 원인을 더 정확하게 잡도록 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.24_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.24_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 살무사 원인 순서**: 살무사가 나온 뒤에 맞은 파도는 원인으로 잡지 않습니다. 살무사 직전(6초 안)에 알이 깨졌으면 그쪽이 원인입니다.
- **알 든 채 사망**: 알 든 사람이 죽어서 알이 깨지거나 떨어진 경우 「알 든 이름 사망 (맞은 기술) → 알 깨짐」으로 적고, 다음 풀 조언은 「알 운반자 힐·생존기 우선 · 피 낮으면 알 넘기기」입니다.
- **울라텍 똥물**: 공대 절반이 이미 죽은 뒤 빠진 똥물은 전멸 원인으로 보지 않습니다.
- **울라텍 킬**: 1:15쯤 매 풀 나오는 막을 수 없는 분노는 킬 화면의 첫 실수로 쓰지 않습니다.
- **똬리 막페 역병의 절단**: 줄잔의 탱 전방 「역병의 절단」에 탱 말고 다른 사람이 맞아 무너진 경우, 직전에 탱이 죽었으면 「탱 사망 → 역병의 절단」으로 판정하고 누가 맞았는지 적습니다. (예전에는 「아직 자동 판정 없음」)

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
