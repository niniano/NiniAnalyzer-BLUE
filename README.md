# NiniAnalyzer Public (BLUE)

WoW 레이드 로그 분석기의 공대 공유용 공개판. 내 WoWCombatLog를 읽어 트라이마다 전멸 원인 · 첫 실수 · 기믹 시간축을 보여 줍니다.

- 처음 쓰는 법: `START_HERE_PUBLIC.txt`
- 변경 내역: `README_1_0_10.md` (이전: `README_1_0_9.md` · `README_1_0_8.md` · `README_1_0_7.md` …)
- 빌드: `Build_Public_EXE.cmd` (PyInstaller) · 설치 파일: `Build_Installer_Only.cmd` (Inno Setup, `installer/`)

## 공개판 원칙
- WCL API 키(`.env`) · 개인 Google Drive 동기화 · 실제 레이드 로그는 들어 있지 않습니다.
- 로그 파일은 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 글꼴: Paperlogy · 펴진고딕 (SIL OFL, `assets/fonts`의 라이선스 참고).
