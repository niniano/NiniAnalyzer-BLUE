# NiniAnalyzer_Public 1.0.29

울라텍 똥물(죽음의 맹독) 판정을 바로잡은 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.29_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.29_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 똥물(죽음의 맹독)**: 똥물 틱은 최대 생명력의 약 11%(탱 약 6.5%)이고 시간이 지나도 같습니다. 잠깐(2틱) 빠졌다 나오면 죽지 않습니다.
  - 여러 공대 로그 409번 빠짐을 보면, 빠진 채 죽은 사람 대부분은 마지막 피해가 괴저 증기 · 근접 공격 · 부패한 막 같은 다른 피해였습니다 (2초 이하로 빠졌다 죽은 60명 중 똥물이 마지막 피해인 건 6명 · 이미 피 2~19%).
  - 결론 글을 「똥물로 사망」(마지막 피해 = 죽음의 맹독)과 「빠진 채 다른 피해로 사망」으로 나눠 적습니다. 원인 판정(여럿이 빠져서 몰살)은 예전과 같습니다.
  - 최종 정리의 「2초 이하로 잠깐 빠져도 n% 사망」을 빼고 「1초에 생명력 약 11% · 빠짐 n번 · 똥물로 사망 n」으로 바꿨습니다. 똥물 보완사항은 똥물이 원인인 트라이가 있을 때만 나옵니다.
  - 다음 풀 문구: 「매초 큰 피해 · 10초면 쓰러짐」 → 「1초에 생명력 약 11% · 잠깐은 버티지만 오래 있거나 피 낮으면 쓰러짐」.
  - 이미 저장된 그날 정리는 처음 열 때 한 번 다시 계산합니다.
