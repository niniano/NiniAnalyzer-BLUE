# NiniAnalyzer_Public 1.0.22

울라텍 똥물(죽음의 맹독) 판정과 붕괴 직전 사망 순서를 더한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.22_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.22_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 「똥물에 빠짐 (죽음의 맹독)」**: 단상과 알방 사이 똥물에 빠지면 「죽음의 맹독」이 붙어 매초 큰 피해를 받습니다.
  · 빠진 사람 · 몇 초 있었는지 · 그래서 죽었는지를 「똥물」 줄로 보여 줍니다.
  · 빠진 사람 중 2명 넘게 죽고 공대가 20초 안에 무너졌으면 전멸 원인 · 첫 실수로 잡고, 다음 풀 조언은 「단상 끝에서 뛰어내리지 말고 정해진 길로 건너기 · 빠지면 바로 나오기」입니다.
- **붕괴 직전 사망 순서**: 원인을 정하지 못한 트라이에서 나오던 「붕괴 직전 10초를 직접 확인하세요」 대신, 그 10초에 누가 무엇에 죽었는지를 순서대로 적습니다.
- **독성 배양은 탱 몫**: 독성 배양 조언 앞에 「탱:」을 붙였습니다. 그 전에 알 → 살무사가 있었으면 다음 풀 조언은 알 쪽을 보여 줍니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
