# NiniAnalyzer_Public 1.0.25

보드 「그날 최종 정리」 칸, 울라텍 「알 든 채 사망」 조언 문구, 똬리 단두대 막은 인원 세기, 똬리 「공포의 통곡 못 끊음」 판정을 담은 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.25_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.25_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **보드 「그날 최종 정리」 칸 (똬리 · 울라텍)**: 트라이 보드 아래에 그날 트라이를 모은 칸이 생깁니다.
  - 왼쪽 「최종 정리」: 그날 수치. 똬리는 1페 전환 시각 · 1페 단두대를 누가 막았나(딜러/힐러 비율) · 막페 2단두대(막페 시작 +84초) 막은 인원과 실패 이유 · 공포의 통곡 차단이 한 사람에게 몰렸나 · 1페 위쪽 공대원이 힐 사거리 밖이던 시간 · 암영폭탄·구슬 뒤 힐러가 떨어져 있던 시간 · 보라구슬 많이 든 사람. 울라텍은 알 운반 실패 종류(부식의 파도 · 알끼리 충돌 · 알 든 채 사망) · 송곳니 줄 끊기 간격과 늦게 끊은 사람 · 큰 알 들기/넣기 시각 · 남쪽 공략 · 똥물에 잠깐 빠져도 죽은 비율 · 탱 사망.
  - 오른쪽 「보완사항」: 다음 주에 고칠 것. 위 3개는 「다음 풀 전에 말할 것」에도 들어갑니다.
  - 「트라이 한눈에」의 핵심 실패는 결론의 첫 실수로, 「반복 실패」는 그날 전멸 원인 묶음으로 바뀝니다.
  - 원본 로그에서 위치·디버프를 한 번 더 읽어서 처음엔 트라이당 몇 초 걸립니다. 도는 동안 「계산 중 n/m트 · 멈춘 거 아님」이 보이고, 한 번 계산하면 트라이 폴더에 저장돼서 다음부터는 바로 나옵니다.

- **알 든 채 사망 조언**: 다음 풀 조언을 「알 운반자 힐·생존기 우선」까지만 씁니다. 알 운반은 특임이 정해져 있어서, 1.0.24 의 「피 낮으면 알 넘기기」는 뺐습니다.

- **똬리 단두대 막은 인원**: 무적기·회피(그림자 망토 · 거북의 상 · 보호막 등)로 받은 사람도 줄에 들어온 사람으로 셉니다. 예전에는 따로 적고 인원에서 뺐습니다. 막페 냉혹한 단두대 뒤 디버프가 이 사람들에게도 똑같이 걸리는 걸 확인했습니다.

- **똬리 공포의 통곡 못 끊음**: 원한에 찬 영혼살무사의 공포의 통곡이 끝까지 시전돼 공대 전체가 공포에 걸리고 바로 무너지면, 그걸 첫 실수 · 전멸 원인으로 잡습니다. 그 쫄을 마지막으로 누가 끊었는지, 이번 풀 차단을 누가 몇 번 했는지도 같이 적고, 다음 풀 조언은 「차단 2~3명 순번 · 1차 차단 직후 다음 차단자 콜」입니다. 단두대·구슬 실패로 보이던 트라이 중 공포 때문에 못 막은 경우가 이걸로 바뀝니다.
