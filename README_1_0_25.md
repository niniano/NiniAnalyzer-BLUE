# NiniAnalyzer_Public 1.0.25

울라텍 「알 든 채 사망」 조언 문구와 똬리 단두대 막은 인원 세기를 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.25_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.25_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **알 든 채 사망 조언**: 다음 풀 조언을 「알 운반자 힐·생존기 우선」까지만 씁니다. 알 운반은 특임이 정해져 있어서, 1.0.24 의 「피 낮으면 알 넘기기」는 뺐습니다.

- **똬리 단두대 막은 인원**: 무적기·회피(그림자 망토 · 거북의 상 · 보호막 등)로 받은 사람도 줄에 들어온 사람으로 셉니다. 예전에는 따로 적고 인원에서 뺐습니다. 막페 냉혹한 단두대 뒤 디버프가 이 사람들에게도 똑같이 걸리는 걸 확인했습니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
