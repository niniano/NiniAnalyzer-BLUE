# NiniAnalyzer_Public 1.0.21

울라텍 알 처리 판정을 더한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.21_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.21_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 「썩은 노른자」**: 작은 알이 손을 떠나면 20초 동안 「썩은 노른자」가 붙습니다. 이게 남은 채로 작은 알을 또 집으면 그 알 껍질 피해가 약 5% 더 들어옵니다.
  · 그런 사람을 「노른자」 줄로 보여 줍니다 (언제 · 누가 · 노른자 몇 초째). 큰 알은 상관없어서 작은 알만 봅니다.
- **알 충돌(맹독성 분출)**: 알끼리 부딪히면 든 사람이 「맹독성 분출」(터질 때 큰 피해 + 10초 동안 계속 피해)을 받습니다.
  · 「알충돌」 줄에 분출을 받고 10초 안에 죽은 사람을 함께 적습니다.

## 개인정보
- 로그는 이 PC 안에서만 읽고 어디로도 보내지 않습니다.
- 「WoW 달력 → 구글」을 직접 켠 경우에만 달력 초대(제목 · 시각 · 내 응답)를 내 구글 캘린더로 보냅니다.
