# NiniAnalyzer_Public 1.0.7

똬리의 제단 · 울라텍 신화 판정을 고친 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.7_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.7_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **똬리 · P1 단두대 붕괴**: 2단두대 처형으로 공대가 무너진 1초 뒤 보스가 0%가 된 트라이를 「P2 · 처형 중심 붕괴 · 첫 실수 없음」으로 적던 것을 고쳤습니다.
  이제 `P1 · 2:13 단두대 붕괴 → 2:32 전멸 (붕괴 뒤 2:14 보스 0%)` · `2번째 단두대 실패 → 처형 ○명 [확정] · 대상 ○○`로 나옵니다.
- **똬리 · 킬 판 결론**: 킬한 트라이도 결론 칸이 채워집니다.
  - 사망 정리: 원인별로 누가 언제 (예: `사망 4명 · 응결된 맹독 2명 (…) · 유독한 지면 1명 (…)`)
  - P2 진입 · 사이페 · 킬 시각을 다른 공대와 비교, 힐러 사망
  - 다음 주: 가장 많이 죽은 원인 두 가지
- **울라텍 · 심장 도중 전멸**: 심장 도중에 전멸한 트라이를 「1심장 종료 ○% · 미달」로 읽고 딜 조언을 붙이던 것을 고쳤습니다.
  이제 `1심장 도중 · 2:31 전멸` · `1심장 도중 전멸 (2:25 시작 · 6초 만) · 딜 판정 안 함`으로 나옵니다.
- 결론 칸은 트라이를 열 때 다시 계산하므로 예전에 가져온 기록도 다시 열면 바뀐 판정이 보입니다.
