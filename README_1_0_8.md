# NiniAnalyzer_Public 1.0.8

울라텍 신화 2페(알방) 큰 알 정리를 더한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.8_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.8_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 알방 큰 알**: 2페(알방)의 큰 알(파멸비늘 알) 4개는 2:54에 부화가 시작돼 4:15 안에 들어야 합니다.
  결론 아래 참고 첫 줄에 `알방 큰 알 1/4 (기한 4:15 · 4:18 전멸) · ○○ 4:07→4:09`처럼
  몇 개를 누가 언제 들고 넣었는지, 기한보다 늦게 든 사람(「늦음」)을 보여 줍니다. 4:15.x 까지 든 것은 제때로 봅니다.
- 알방 알 단계 전에 끝난 트라이에는 나오지 않습니다. 결론 칸은 트라이를 열 때 다시 계산하므로 예전 기록도 다시 열면 보입니다.
