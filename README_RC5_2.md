# (RC5 내용)

RC4.4에 GOLD V4.7 R2의 트라이 화면과 네크잘리 판정 보강(boss_guides V1.4)을 합친 버전입니다.
저장 형식·엔진 판정·가져오기는 RC4.4와 같습니다. 바뀐 것은 화면입니다.

## 바뀐 것 (공대원이 보는 화면)
- **결론 5줄과 단계 칩**: 전멸 트라이 맨 위에 어디까지 · 첫 실수 · 전멸 원인 · 딜·힐 · 다음 풀이 나옵니다.
  - 단계 칩 색: 넘긴 단계는 초록, 전멸한 단계는 빨강, 못 간 단계는 회색입니다.
- **색**: 기믹 이름은 종류마다 늘 같은 색이고, 캐릭터 이름은 직업색입니다.
- **기믹 시간축**: 기본 보기가 「스킬별」 줄(Viserio 방식)입니다. 「한 줄」 · 「상세(기존)」로 바꿀 수 있습니다. 아이콘 테두리는 1px입니다.
- **공략 판정 보스**: 똬리 · 울라텍에 더해 스조라크 · 쌍둥이 송곳니 · 매장된 파수꾼 · 악성의 바쉬니크 · 영혼살무사 네크잘리 · 길 잃은 탐험가가 추가됐습니다.
  - 네크잘리: 「각성의 그릇 (시체 못 태움)」을 판정합니다. 각성의 그릇은 죽은 잠 못 드는 아마니가 남기는 시체로, 굶주린 장작더미나 기어가는 불꽃(화장)으로 태워야 합니다.
  - 네크잘리: 고뇌의 메아리 착지 · 잠복한 이교도 장판 · 화장 폭발 사망도 따로 구분합니다.
  - 신화 트라이에는 「같은 시각 우리 킬 HP」와 다른 공대 킬 시간이 붙습니다. 영웅 트라이에는 붙지 않습니다.
- **세로 모니터**(예: 1440×2560): 창이 1440×1640으로 열리고 화면 밖으로 나가지 않습니다. 환경변수 `WCLA_TALL=0`이면 꺼집니다.
- **트라이 스크롤**: GOLD HF4/HF6 방식을 씁니다. 마우스가 트라이 화면 위에 있으면 휠이 스크롤되고, 세로 스크롤바는 항상 보입니다.

## 공개판에서 빠진 것 (개인용)
- 개인 아카이브 · 외부 WCL 비교 · 개인 Drive 동기화 모듈은 들어가지 않습니다.
- GOLD 전용 자료(공대 연대기 색인, 개인 감사 기록)도 들어가지 않습니다.
- 「그 순간의 행동」 개인 칸은 공개판에서 표시되지 않습니다. 소스의 이름도 「내 캐릭터」로 바꿨습니다.

## 빌드 (Windows · Python 3.12/3.13)
1. 이 폴더를 통째로 풀고 `Build_Public_EXE.cmd`를 실행합니다.
2. 순서: `verify_release.py` 게이트 → qa 테스트 → PyInstaller → ZIP 봉인 → 설치 파일.
3. 결과:
   - `dist\NiniAnalyzer_Public_1.0.0-rc5_Setup_Windows_x64.exe` (공대원에게 배포)
   - `dist\NiniAnalyzer_Public_1.0.0-rc5_Windows_x64_SAFE_FOLDER.zip` (설치 없이 쓰는 판, 선택)

## 이 키트에서 확인한 것 (Linux · Xvfb)
- `verify_release.py`: 모든 게이트 통과 (RC5 게이트 추가).
- qa 83개 테스트 통과. RC5 테스트 5개가 새로 추가됐습니다.
  - 새 모듈이 PyInstaller hidden-import에 들어갔는지 확인합니다.
  - EXE에서 `.py`가 없어도 보스 판정 모듈을 찾는지 확인합니다.
  - 개인 자료가 빠졌는지, 네크잘리 판정이 있는지 확인합니다.
- 휠 테스트 3개는 GOLD HF4 기준(포인터 위치 + 트라이 영역)으로 고쳤습니다.
- 소스 전체에서 공대원 이름 89개와 개인 경로를 검사했고, 남은 것은 없습니다.
- 공개 모드(`App(edition="raid")`)로 저장 기록 76개를 열어 화면을 확인했습니다.

## 손대지 않은 것
- 사용자 기록(`%LOCALAPPDATA%\NiniAnalyzer\Public`)은 그대로 둡니다. 다시 분석할 필요가 없습니다.
- 설치 파일은 공대 기록을 지우지 않습니다(`UninstallDelete` 없음).
