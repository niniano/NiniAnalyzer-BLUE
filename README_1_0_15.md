# NiniAnalyzer_Public 1.0.15

실시간 감시 중 마지막 트라이 따라가기와 울라텍 큰 알 판정을 보완한 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.15_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.15_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **마지막 트라이 따라가기**: 실시간 감시 중 트라이 복기가 끝나면 그 트라이 화면으로 바로 넘어갑니다.
  · 트라이 사이에 지난 트라이를 눌러 보는 건 그대로 되고, 다음 트라이가 끝나면 다시 마지막으로 갑니다.
  · 놓친 트라이를 채우는 중에는 화면을 옮기지 않습니다.
- **울라텍 큰 알 → 공포의 포효**: 큰 알을 안 집어 4:24에 나온 게걸스러운 파멸비늘이 「공포의 포효」로 공대를 공포에 빠뜨려 무너진 판을
  첫 실수 · 전멸 원인으로 [확정] 표시합니다 (전에는 원인 미확정으로 나옴).
- **붕괴 뒤 절규**: 이미 무너진 뒤의 고통스러운 절규 미차단은 첫 실수가 아니라 결과로 봅니다.
- **근접 공격 출처**: 「근접 공격 N명」 붕괴에 누가 때렸는지 붙입니다 (예: 역병비늘 유체 근접 공격). 유체 때문에 무너졌으면 다음 풀도 유체 조언이 나옵니다.
- **큰 알 알림 기준 한 줄**: 「큰 알 들기 알림 4:12 → 실제 · 마지막 알림 4:19 · 부화 4:24 · 넣음」을 한 줄로 보여 줍니다. 늦음 판정은 마지막 알림(4:19) 기준입니다.
