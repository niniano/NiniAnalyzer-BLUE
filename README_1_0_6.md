# NiniAnalyzer_Public 1.0.6

개인 분석기(GOLD)에만 먼저 들어갔던 판정 · 화면 개선을 한 번에 가져온 판입니다.

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.6_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.6_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **키식스 판정 보강**
  - 유동 신화(233)로 저장된 키식스도 신화 기준(다른 공대 기준선 · HP 체크)으로 봅니다.
  - 「기믹 수행 체크」 칸: 빛구슬 · 빛 안 · 쫄·알 처리 · 딱정벌레 · 일월식 파편 · 촉수·공허흉터 · 무효화 중첩 · 탱 교대 · 공포 중 리혼·결의
  - 딱정벌레 소화액도 피할 수 있는 실수로 셉니다. 무효화 3중첩 즉사는 「무효화 3중첩 즉사」로 따로 묶습니다.
  - 확정 원인은 붕괴 앞뒤 사망만 보고, 붕괴 뒤 이어진 다른 실패는 「→ 결과」로 붙입니다.
- **킬 판 결론 · 보스 보드**
  - 킬한 트라이도 결론 칸에 사망 정리 · 다음 주 · HP 체크가 나옵니다.
  - 전용 엔진 판정이 없는 보스도 보스 보드에 결론 5줄로 보입니다.
  - 시간축에서 거의 같은 시각에 겹친 같은 기믹은 하나로 그리고 ×n 을 붙입니다. 판정 순서가 비었을 때 문구도 결론 줄과 맞췄습니다.
- **똬리 신화 정확도**
  - 「P1 단두대 소킹」 칸: 단두대마다 실제로 맞은 인원(○/6명)과 처형 · 연계 사망
  - 붕괴보다 뒤에 난 실패는 첫 실수로 치지 않습니다.
  - 일몰 시전이 끝난 뒤 보호막이 사라진 것은 「파괴」가 아니라 「해제 · 파괴 미확정」으로 표시합니다.
  - P1 전환이 늦어지는 구간의 맹독성 파열 집단 사망을 관측으로 보여 줍니다 (원인 단정은 하지 않음).
  - 이 버전 전에 가져온 똬리 신화 기록은 소킹 칸이 「재분석 필요」로 보입니다. 새로 가져온 로그부터 채워집니다.
