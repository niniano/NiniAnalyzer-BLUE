# NiniAnalyzer Public 1.0.0-rc4.3 · 빌드 키트

Windows 검증을 마친 RC4.2 v2에 **풀러/첫 공격자 이름 직업 색**만 추가한 버전입니다. 다른 기능·엔진은 RC4.2 v2와 같습니다 (세부: `README_RC4_2.md`).

## 바뀐 것
- 트라이 화면 제목 아래 `풀러 ○○ (1.2초 전 · 스킬)` / `첫 공격 ○○ (+0.0초 · 스킬)`의 **이름만** 와우 직업 색으로 표시
- 직업은 그 트라이의 공대원 정보(전투 기록의 전문화)로 판단 → 이미 가져온 기록도 재분석 없이 색이 들어감
- 펫이 먼저 친 경우: 주인 직업 색 + `[펫]`
- 전문화 정보가 없거나, 판단 보류(동시 공격)·분석 대기 문구는 기존 색 그대로

## 빌드
`Build_Public_EXE.cmd` → `dist\NiniAnalyzer_Public_1.0.0-rc4.3_Setup_Windows_x64.exe`
RC4.2와 같은 AppId라 기존 설치 위에 그대로 업데이트됩니다(기록 유지).

## 확인할 것 (짧게)
1. 설치 후 왼쪽 위 버전 `v1.0.0-rc4.3`
2. 트라이 화면 첫 공격자 이름이 직업 색인지 (예: 마법사 하늘색, 사냥꾼 연두)
3. 스크롤·설정 > 죽척 재검사가 RC4.2처럼 동작하는지

## 검증
- 공개판 QA 71개 통과 (RC4.2 v2 64 + 직업 색 7), `verify_release.py` RC4.3 게이트 통과
- 실제 가져온 기록 화면에서 냉기 마법사 첫 공격자 → `#3FC7EB` 표시 확인
- 엔진·저장 파일 변경 없음 (화면 표시만)
