# NiniAnalyzer_Public 1.0.5

울라텍 신화의 알 운반 → 살무사 판정을 더한 판입니다. (1.0.4는 건너뛰었습니다)

## 받기
- **설치 파일 (추천)**: `NiniAnalyzer_Public_1.0.5_Setup_Windows_x64.exe`
- **설치 없이 쓰기**: `NiniAnalyzer_Public_1.0.5_Windows_x64_SAFE_FOLDER.zip` (압축 풀고 `NiniAnalyzer_Public.exe` 실행 · `_internal` 폴더는 그대로 두기)
- 파일이 맞는지 확인하려면 같은 이름의 `.sha256.txt`

## 업데이트
- 새 설치 파일로 그냥 덮어 설치하면 됩니다. 가져온 공대 기록과 설정은 그대로입니다.

## 바뀐 것
- **울라텍 신화 · 알 운반 → 살무사**
  - 알 든 사람(유독한 껍질)이 부식의 파도에 맞거나 알끼리 부딪히면(맹독성 분출) 곧바로 역병비늘 살무사가 나옵니다.
  - 붕괴 25초 안쪽에서 살무사가 먼저 나왔으면 그게 전멸 원인으로 나옵니다. 예: `알 든 ○○ 부식의 파도 1:57 → 살무사 2마리 1:58 → 붕괴`
  - 붕괴보다 한참 앞선 막을 수 없는 분노는 첫 실수로 치지 않고 참고로만 적습니다.
- **참고 줄에 알 · 살무사 전부**
  - 알 든 사람이 맞은 부식의 파도 전부(이름 · 시각)와 살무사 마리 수
  - 살무사가 찍은 사람 → 5초 뒤 착지 스턴에 같이 걸린 사람. 스턴 없이 끝난 주시는 「주시(스턴 없음)」
- 신화 · 원본 로그가 있는 트라이만. 트라이를 열 때 다시 계산하므로 예전에 가져온 울라텍 기록도 다시 열면 보입니다.
